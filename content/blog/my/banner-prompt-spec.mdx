### Prompt

> ဒီ prompt က ChatGPT ဒါမှမဟုတ် Gemini လို AI chat တွေမှာ အလုပ်ဖြစ်ပြီး image-only tool တွေမှာတော့ အလုပ်မဖြစ်ပါဘူး။ [limitations and workaround](#tool-support)

## အသုံးပြုပုံ

1. Spec တစ်ခုလုံးကို ChatGPT၊ Gemini ဒါမှမဟုတ် ပုံ generate လုပ်ပေးနိုင်တဲ့ တခြား AI chat ထဲ paste လုပ်ပါ။
2. သူမေးတဲ့ interview ကို ဖြေလည်းရတယ်၊ မဖြေလည်းရတယ်။ မေးခွန်းတစ်ခုချင်းစီ မေးသွားပြီး အဲ့ဒီ option တွေထဲက သင့်တော်မယ့်တစ်ခုကိုပါ အကြံပေးထားမယ်။ တစ်ခုပြီးတစ်ခု ကိုယ့်စကားနဲ့ကိုယ် ဖြေလို့ရသလို မေးခွန်းတစ်ခုအတွက် `your pick` လို့ပဲ ပြောလို့လည်းရတယ်။ အဲ့လိုမှမဟုတ်ဘူး ကျန်တာအားလုံး သူ့ဘာသာ ရွေးပေးစေချင်ရင် `choose the rest for me` လို့ ပြောလိုက်ရုံပါဘဲ။
3. AI ကပေးတယ့် Summary ကို သေချာစစ်ပါ။ ပုံမဆွဲခင်မှာ lock လုပ်ထားတဲ့ option အားလုံးနဲ့ ပုံထဲက figure ကိုင်ထားမယ့် ပစ္စည်းအတိအကျကို ပြောပါလိမ့်မယ်။ ပြင်စရာရှိရင် generate လုပ်ပြီးမှ မပြင်ဘဲ ဒီနေရာမှာတင် ပြင်ရင် ပိုပြီးကောင်းပါတယ်။​ (အထူးသဖြင့် free plan နဲ့သုံးတယ့်သူတွေအတွက်ပါ)
4. အားလုံးမှန်ရင် confirm လုပ်ပါ။ ပြီးတာနဲ့ Banner image လေး generate လုပ်ပေးပါလိမ့်မယ်။

ပုံထဲမှာ ပါလာမယ့်စာက ကိုယ်ရေးပေးထားတဲ့ copy တစ်ခုပဲ။ ဒါကြောင့် မစခင် headline ကို အရင်ရေးထားပါ။ စာလုံး ကိုးလုံးထက် မပိုရဘူး။ Linkedin မှာ သုံးမယ်ဆို ကိုယ့်နာမည်နဲ့ အလုပ်အကိုင်ကိုလည်း က profile ထဲမှာပါပြီးသားမလို့ headline ထဲ ထပ်မရေးဖို့အကြံပေးချင်ပါတယ်။ |

## ရေးသူရဲ့ မှတ်ချက်

ဒီ prompt ကို မသုံးခင် သိထားသင့်တာတစ်ခု ရှိတယ်။

သူ့မှာ ရွေးချယ်လို့ရတဲ့ variant (design အရေအတွက်ကို) ပုံသေသတ်မှတ်ထားတယ်။ လူအများစုက ဘာမှမပြောင်းဘဲ prompt ကိုဒီအတိုင်းသုံးဘဲသုံးမယ်ဆိုရင် banner တွေက တစ်ခုနဲ့တစ်ခု ဆင်နေပါလိမ့်မယ်။

ဒါကြောင့် ဒီ prompt ကို ကိုယ်ပိုင် banner တစ်ခု generate လုပ်ဖို့အတွက် အစပြုစရာတစ်ခု၊ idea ယူစရာတစ်ခုလို့ပဲ သဘောထားပါ။

သုံးလို့ရတဲ့ system တစ်ခုတော့ သူက ပေးမယ်။ ပြီးတော့ ရလာတယ့် Image တွေကို ကိုယ့်အကြိုက်နဲ့ ကိုက်အောင် unique ဖြစ်အောင် အစိတ်အပိုင်းတိုင်းကို လိုသလိုလိုက်ပြောင်းရင် ပိုကောင်းပါလိမ့်မယ်။

> ထွက်လာတဲ့ result ကို ဒီအတိုင်းကြိုက်တယ်ဆိုလည်း ဘာမှမဖြစ်ဘူး။ ဒီအတိုင်းသုံးလို့ရပါတယ်။ မဖြစ်မနေ ပြောင်းစရာတော့မလိုပါဘူး။

ဒါပေမယ့် ကိုယ်ပိုင်ပုံစံ design နဲ့ အများနဲ့ မတူအောင်လုပ်ရင်တယ်ဆိုရင် ကျွန်တော် လုပ်ခဲ့တယ့် process ကို အောက်မှာ ရှင်းပြထားပါတယ်။

1. **Pinterest ကို အရင်သွားပြီး art တွေ ကြည့်ပါ။** ကျွန်တော်က marble sculpture art နဲ့ painted classical art တွေကို ရှာပြီး ကြိုက်တာတွေ save ထားခဲ့တယ်။ ပြီးတော့ designer တခြားလူတွေက halftone dot၊ grain fade လို effect တွေကို ဘယ်လိုသုံးလဲ သိချင်လို့ effect တွေ ထပ်ရှာကြည့်တယ်။

   ဒီနေရာမှာ သတိထားရမယ့် အရေးကြီးတာတစ်ခု ရှိတယ်။ အဲ့ဒီပုံတွေကို reference အနေနဲ့ပဲ သုံးပါ။ ကူးချဖို့တော့ လုံးဝမသုံးပါနဲ့။ Pinterest ပေါ်က ပုံတွေမှာ ဖန်တီးထားတဲ့သူတွေရဲ့ ပိုင်ဆိုင်ခွင့်ရှိပြီး အများစုက အလကားယူသုံးလို့ရတာ မဟုတ်ပါဘူး။ ဒါကြောင့် ကိုယ်လိုချင်တဲ့ style ကို နားလည်ဖို့ပဲ ကြည့်ပါ။ အဲ့ဒီ style ကို ကိုယ့်စကားနဲ့ကိုယ် ပြန်ဖော်ပြပြီး AI ကို အသစ်တစ်ခု generate လုပ်ခိုင်းပါ။

2. **ကိုယ်မြင်တာကို ချရေးပါ။** ကြိုက်တဲ့ art style တစ်ခု တွေ့ပြီဆိုရင် prompt ထဲက direction တွေ ရေးထားတဲ့ပုံစံအတိုင်း လိုက်ရေးကြည့်ပါ။ Figure က ဘာလုပ်နေလဲ၊ camera က ဘယ်လောက်နီးလဲ၊ surface က ဘယ်လိုလဲ၊ lighting က ဘယ်လိုကျလဲ—ဒီအချက်တွေကို ရေးပါ။ ပြီးရင် option အသစ်တစ်ခုအနေနဲ့ list ထဲ ထည့်လိုက်ပါ။

3. **အရောင်တွေ ပြောင်းပါ။** Palette လေးခုဆိုတာ hex value တွေပါတဲ့ စာကြောင်းလေးကြောင်းပဲ။ Prompt ထဲက တခြား rule အားလုံးက အရောင်နာမည်ကို တိုက်ရိုက်မခေါ်ဘဲ သူ့အလုပ်အလိုက် field၊ ink၊ secondary၊ accent လို့ပဲ သုံးထားတယ်။ ဒါကြောင့် hex code တွေကိုပဲ အစားထိုးလိုက်ရင် တခြားဘာမှ မပျက်ဘူး။

## ဘယ် AI tool တွေမှာ အလုပ်ဖြစ်လဲ

ဒီ prompt က ပုံတစ်ပုံ တန်းထုတ်ခိုင်းတဲ့ one-shot request မဟုတ်ဘဲ AI နဲ့ စကားပြောရတဲ့ conversation တစ်ခုပါ။ ChatGPT ဒါမှမဟုတ် Gemini လို AI chat တွေမှာသာ အလုပ်ဖြစ်ပါတယ်။ အဲ့ဒီမှာ model က မေးခွန်းတွေ မေးပြီး ပုံကို အဲ့ chat ထဲမှာဘဲ generate လုပ်ပေးတယ်။ ဖော်ပြချက်တိုတိုလေးပေးလိုက်ရုံနဲ့ ချက်ချင်းပုံထုတ်ပေးတဲ့ image-only tool တွေမှာတော့ အလုပ်မဖြစ်ပါဘူး။ Spec က ရှည်ပြီး rule တွေများတဲ့အပြင် အရင်ဆုံး interview လုပ်ဖို့လည်း လိုအပ်လို့ပါ။

image-only tool နဲ့ပဲ သုံးချင်သေးတယ်ဆိုရင်တော့ အရင်ဆုံး ChatGPT ဒါမှမဟုတ် Gemini မှာ ဒီ prompt ကို run ပြီး interview ကို ဖြေပါ။ ပြီးရင် ကိုယ်ရွေးထားတဲ့ option တွေကို image prompt တိုတိုလေးတစ်ခုအဖြစ် ပြောင်းပေးဖို့ တောင်းပါ။ အဲ့ဒီ short version ကို ကိုယ့် image tool ထဲ paste လုပ်ပါ။ Full spec ရဲ့ rule အားလုံးကိုတော့ လိုက်နာမှာ မဟုတ်ပေမယ့် အနီးစပ်ဆုံးတော့ ရပါလိမ့်မယ်။

ပြီးတော့ ဒီ prompt ကို ChatGPT ပေါ်မှာပဲ ကျွန်တော် စမ်းဖူးသေးတယ်။ ဘယ် model မှာမဆို သုံးလို့ရအောင် ရေးထားပြီး တခြားနေရာတွေမှာလည်း အလုပ်ဖြစ်မယ်လို့တော့ထင်ပါတယ်။
